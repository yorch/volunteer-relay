# Synthetic benchmark v1

All names, tenants, messages and image bytes are invented. `sources.json` contains 28 updates; `expected-results.json` is a separately authored manual oracle, never generated from application output. The first four messages represent one visit and its amendment, not four visits. Missing duration remains null. Final totals assume staff review, under both policies. Phase 0 tests validate integrity and coverage, not extraction accuracy. The color PNGs deliberately contain no identities or temporal evidence; later scene-photo fixtures must retain independent annotations.
