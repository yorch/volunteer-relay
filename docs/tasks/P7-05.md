# P7-05 — Closed operator organization provisioning

A explicitly delegates scripts/provision-organization.ts, tests/integration/provisioning/** and docs/provisioning.md to the product acceptance implementer. Only a new organization and initial owner for an existing verified credential account may be provisioned. Never create/log a password, promote a user in an existing tenant, or expose this privilege through HTTP. Use a private PostgreSQL test database and preserve all existing source/history. A integrates linearly to main after review and tests.
