4. Present needs by lifecycle status; move creation and detailed edits behind clear actions. Preserve all assignment, acknowledgment, deadline, escalation and provisional behavior.

6. Refine reports into a board-ready summary with compact filters and readable duration formatting. Keep CSV and UI query definitions identical.
7. Compare import preview/mapping/error/confirmation and the real volunteer form/status flow against the reference using the appropriate roles.

Inspect screenshots and keyboard interactions, touch targets, labels/focus, contrast and overflow. Check restricted role navigation and source selection through filter changes. Record intentional visual deviations and their reasons; do not claim parity from test counts alone. No live model, external messaging or production data is required for this design task.
