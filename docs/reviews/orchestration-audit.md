## Operating boundaries

- The watchdog observes and issues bounded informational nudges. It is not an automatic deployment manager: a dead supervisor, unresolved permission rejection or explicit operator hold is never silently replaced/unpaused.
- Explicit task assignment is coordinator authorization; phase-gate review and frozen contracts remain mandatory. Backlog planning neither authorizes all task cards nor infers prose dependencies.
- Unknown legacy scopes and review pins are reported as such. Coordination rules are not a hostile multi-user security boundary or an OS filesystem sandbox.
- Native tool output/reasoning remains omitted from normalized traces. Historical token counters are not certified provider billing; cache/usage adapter and UI features are separate scoped work.
- A single exclusive local store is required. Do not run the supervisor against the application's checkout while that session owns its writes. This audit ends with the supervisor stopped; activation is an explicit later operator decision.
