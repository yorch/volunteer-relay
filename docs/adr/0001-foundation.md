# ADR 0001 — Phase 0 foundation

Accepted 2026-11-07. Follow the plan's confirmed stack: Next.js/TypeScript, separate Node 26 web and worker, Bun workspace installation, PostgreSQL/Drizzle, Better Auth, Biome/Vitest, MIT. Bun is never the runtime. Native Node TypeScript stripping runs worker and scripts; Next compiles web. Worker build copies erasable TypeScript, with workspace source dependencies retained in its image. No business schema, auth routes, queue execution, extraction or notification behavior is implemented at M0.

Accepted planning defaults: pg-boss plus transactional application outbox; Tailwind and accessible reusable components; SMTP with local Mailpit; private shared filesystem behind tenant-authorized reads with storage port; one bot per deployment with explicit organization selection; English/Spanish intake and English UI; small Playwright smoke suite later. Their dependencies are added only when the owning task implements them. OpenAI model remains configuration selected by fixture evaluation, never an assumed latest model. Local color PNGs are attachment integrity fixtures, not an extraction accuracy benchmark.

Local Compose provides Postgres, Mailpit, web and worker. Its web command uses the Next development server with a matching development environment; the image build separately verifies production compilation. Host ports are configurable to coexist with other local projects. Production proxy/TLS, least privilege roles, migration startup gating, backups and monitoring are P7; do not expose this local topology publicly. M0 migrations and seeding are explicit no-ops because B owns P1 schema. Shared contract review is coordinator-owned; future port additions are gated before dependent implementation.
