## Design direction to carry forward

Use the prototype as the visual reference for the warm off-white/sage surfaces, dark teal actions, restrained amber/red states, Manrope headings and DM Sans body text (or deliberate accessible fallbacks), rounded bordered cards, spacious staff shell and short supportive copy. Reuse the visual hierarchy of list → source evidence → proposed fields, the need ownership/acknowledgment board, compact summary cards, and the volunteer's simple text-first form. CSS breakpoints at 760/1200/1500px express intent; E must validate actual layouts rather than copy breakpoints blindly. The fake phone frame is a presentation device; production volunteer routes use the viewport without staff navigation or simulated device chrome.
