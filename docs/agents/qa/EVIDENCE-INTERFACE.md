# Evidence v1 handoff interface

Canonical coordinator interface: scripts/evidence/contract.ts (A-owned/read-only to F). F is explicitly delegated ONLY P0-20 store/capture/test/pilot paths. Implement `createEvidenceStore(root, limits?) -> Promise<EvidenceStore>` in store.ts; no API/dashboard/trace edits. A will integrate P0-22 serving/gallery and opaque P0-15 links. No application/shared package entity added.

Run IDs are `qa_` plus32 lowercase UUID hex; artifact IDs `ev_` plus32hex, finding IDs `finding_` plus32hex. Store generates run/artifact IDs, stamps ISO time and computes SHA256 bytes. task is Pn-nn, testedCommit40hex. Partition private storage by validated task/run/commit/scenario/browser/viewport and opaque identity; files0600/dirs0700. Manifests version1 save incrementally/atomically, no raw paths in public records. `list` page limit1..20, cursor is opaque run ID only; absent/rejected items never expose driver paths. `read` returns only known manifest-bound safe image/video bytes; A performs additional readonly HTTP policy. Reject symlink directories/files, traversal/non-IDs, malformed/oversize manifests/content and MIME mismatch; root containment is canonical, not string prefix. Existing manifest data must not be trusted blindly on restart.

Routes/scenarios are finite safe keys, no query strings or invitation/token path values. No arbitrary labels/URLs/metadata bags. Preserve original finding artifacts and associate recheckOf, never overwrite originals. Default screenshot PNG, explicit optional bounded WebM (max16MiB artifact/max30s scenario), not constant recording. Video enabled only by explicit capture option. Retention within frozen caps: prefer removing successful oldest video before failure evidence; report truncation/omitted counts and retention boundaries. Concurrent append serialization must avoid lost manifests. When run cap reached record truncation then reject append with bounded safe error; global retention may prune old completed runs safely. Never follow external paths supplied in a manifest.

`capture.ts` may import Playwright types and operate on a caller-owned Page/BrowserContext; screenshots at meaningful initial/interaction/pending/error/success/responsive/finding/recheck checkpoints. No own uncontrolled website/server navigation. Local synthetic pilot may start its OWN127.0.0.1:3193 server, capture screenshot and explicit short video, inspect/reopen bytes/hash/manifests and stop its processes. No DB/provider/models or external network. Browser evidence must be actually collected, not fabricated fixtures; unit expectations independently authored. Pixel/video safety is caller responsibility: only synthetic non-sensitive states, no credentials/tokens/cookies/private source; text redaction does not protect pixels. Never store raw Playwright trace archives in this store. Report what capture/viewing was actually tested; A gallery acceptance waits for real API/browser viewing.
